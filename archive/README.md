# Archive: non-authoritative provenance

Files under `archive/` are retained only to document the development history. They are not the source of the final manuscript results and are excluded from the recommended reproduction workflow.

- `legacy-notebooks/` contains older exploratory notebooks from `coding.zip`; several are partial or contain stored errors and local absolute paths.
- `original-correction-scripts/` contains the original hard-coded statistics script before it was made portable.

Use `notebooks/core/`, `src/`, `results/`, and `artifacts/` for reproducibility and citation.
